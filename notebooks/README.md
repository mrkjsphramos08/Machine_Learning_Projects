# Notebooks Directory

This folder is reserved for **exploratory data analysis (EDA)**, rapid prototyping, and one-off visualizations.

### MLOps Best Practice:
Once an idea works in a notebook, **refactor it into modular Python scripts inside `src/`**. 
Notebooks are great for exploration, but poor for:
- Automated production pipelines
- Version-controlled unit testing
- Continuous integration (CI/CD)
