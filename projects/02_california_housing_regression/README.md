# Project 02 — California Housing Regression

Predicting median house value for California districts from demographic and geographic features, using the **scikit-learn California Housing dataset** (derived from the 1990 U.S. Census).

| Property | Value |
| :--- | :--- |
| Source | `sklearn.datasets.fetch_california_housing()` (saved to `data/raw/california_housing.csv`, tracked by DVC) |
| Rows | 20,640 |
| Features | 10 (8 base + 2 engineered: `bedrooms_ratio`, `rooms_per_person`) |
| Target | `MedHouseVal` — continuous, median house value in $100,000s (range: ~0.15 to 5.0) |
| Task | Continuous Regression |
| Primary metric | RMSE (lower is better), MAE, and R² |
| Best Model | `HistGradientBoostingRegressor` (R²: **0.8443**, RMSE: **0.4517**) |

## Commands

Run from **this folder**:

```powershell
cd projects\02_california_housing_regression

python -m src.data      # regenerate data/processed/*.parquet
python -m src.train     # train model and log run to MLflow
python -m src.evaluate  # run full diagnostics (CV, overfitting check, residuals)
pytest                  # hermetic smoke + data validation tests
```

Run from the **repo root**:

```powershell
.\.venv\Scripts\Activate.ps1
dvc repro projects/02_california_housing_regression/dvc.yaml   # reproduce entire pipeline
mlflow ui --port 5000                                          # inspect experiments in UI
```
